# Menu de maman

Site cuisine mobile-first pour planifier les repas de la semaine, consulter les recettes et generer la liste de courses.

Fonctions incluses :
- favoris et recettes refusees ;
- generation avec les ingredients deja disponibles ;
- installation sur telephone comme une appli.

## Publication GitHub Pages

Publier ce dossier dans un depot GitHub dedie, puis activer GitHub Pages sur la branche `main`.

Le fichier d'accueil est `index.html`.
